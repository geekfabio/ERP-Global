# Identidade visual — ERP-Global

Conceito: **livro aberto** (educação) sob um **globo de nós ligados** (plataforma integrada); nó âmbar = destaque/acento.

| Ficheiro | Uso |
|---|---|
| `symbol.svg` / `symbol.png` | Símbolo a cores (fundo claro) |
| `symbol-dark.svg` | Símbolo para fundo escuro |
| `symbol-mono.svg` | Uma cor (`currentColor`): impressão, carimbos, marca de água |
| `logo-horizontal.svg` / `-dark.svg` | Cabeçalhos, login, PDFs |
| `logo-vertical.svg` | Ecrã inicial, capas |
| `app-icon.svg` / `app-icon.png` (1024²) | Ícone da app (launcher) |
| `favicon.svg` | Favicon web |

Paleta: azul `#0B3D91`, teal `#14A3A1`, âmbar `#F5A623`, navy `#0A1F44`. Dark: `#5B8DEF` → `#2DD4BF`.
